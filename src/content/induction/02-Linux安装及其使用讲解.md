在进入 RoboMaster 视觉组的实质性开发之前，你需要具备一个合格的系统环境。本篇文档是关于 Linux 环境部署的第一部分。

## 1. 选择 Ubuntu 的原因

对于视觉算法开发和机器人工程而言，Windows 并非理想的生产力环境。我们统一要求安装 Ubuntu 的主要原因如下：

*   **硬件接口的透明性**：视觉开发需要高频调用工业相机、USB 转串口等模块。Linux 提供了更直接、底层的硬件读写权限，避免了 Windows 下复杂的闭源驱动冲突。
*   **ROS 生态支持**：机器人操作系统（ROS/ROS 2）是 RM 视觉组与底盘电控通信的基础。Ubuntu 是 ROS 官方支持最完善的宿主系统。
*   **编译效能**：C++ 项目（CMake + OpenCV）在 Linux 环境下的包管理（`apt`）和编译链体验更为流畅和规范。

### 2.2 装机前置概念理解

在点开外部文档或视频教程前，请先理解以下四个核心概念的底层逻辑。这不仅是装双系统的必经之路，也是防止你误操作导致原有 Windows 数据损毁的常识。

**1. ISO 镜像与启动盘（解决"引导"的问题）**
*  Ubuntu 系统本身是一个巨大的数据包（即 `.iso` 文件）。电脑在日常状态下，无法直接"双击"运行并安装它。
*   **做法**：你需要准备一个空白 U 盘，并借助 Rufus 或 Ventoy 等烧录工具，将 ISO 文件写入其中。这个过程相当于把普通 U 盘改造成了一把**能够独立启动电脑的物理钥匙**。插上它开机，电脑才能跳过你硬盘里的 Windows，直接进入 Ubuntu 的安装环境。

**2. 磁盘分区压缩**
*   在 Windows 自带的"磁盘管理"工具中，强制从现有的磁盘中切出一块"未分配"的空白空间。
*   **为什么要这么做**：你的硬盘就像一块已经被完全划分好的地皮。Ubuntu 是一套全新的系统，它不会和 Windows 挤在同一个分区的房间里。如果你不提前在 Windows 里把地皮切出一块空白区域，Ubuntu 安装程序就找不到空地。**如果在没有空白空间的情况下强行安装，极易导致整个硬盘被意外格式化。**
*   *注：考虑到视觉组后期需要存储大量编译文件、深度学习数据集，内录视频等等。建议此处至少切出 200GB 以上的未分配空间。*

**3. 关闭 Secure Boot / 安全启动**
*   Secure Boot 是主板 BIOS 层面的一项底层安全机制。你可以把它理解为**微软联合主板厂商设置的"系统保护"**。
*   **为什么要这么做**：默认情况下，这个保卫只允许带有微软数字签名的系统（也就是 Windows 本身）启动。如果你不进入主板后台把该选项关掉（设为 `Disabled`），电脑就会把你插上的 Ubuntu U 盘当作非法程序直接拦截，你将永远卡在 Windows 里。此外，如果不关闭该机制，后续安装 Nvidia 闭源显卡驱动时也会被系统拦截，导致开机黑屏。

**4. 磁盘加密（BitLocker / 设备加密）**
*   预装 Windows 11 的电脑默认开启磁盘加密（BitLocker 或"设备加密"）。**改动磁盘分区或 BIOS 设置会触发它的防篡改机制**，重启时要求输入恢复密钥，输错就进不了系统。
*   **做法**：安装前在 Windows 里**关闭 BitLocker / 设备加密**，或者至少把**恢复密钥** 备份到手机或 U 盘。

### 2.3 Windows 侧的准备工作

安装前建议在 Windows 里完成以下几件事（内容来源见 2.1 的图文教程）：

1. **关闭设备加密 / BitLocker**（见 2.2 第 4 条）；
2. **关闭"快速启动"与"休眠"**：`控制面板 → 系统和安全 → 电源选项 → 选择电源按钮的功能 → 更改当前不可用的设置`，取消勾选"启用快速启动"和"休眠"。否则 U 盘引导可能被跳过、对分区的改动也更容易出问题；
3. **建议暂停 Windows 更新**：更新往往带来更多 Bug，并可能导致 Ubuntu 无法启动，安装后尽量不使用 Windows 更新；
4. **磁盘分区压缩**：切出至少 200GB 未分配空间（见 2.2 第 2 条）。

### 2.4 硬件特异性与易错问题

由于各品牌电脑（联想、华硕、戴尔等）的主板设计与出厂预装策略不同，你可能会在进入引导盘或安装过程中遇到特异性阻拦。以下是四个最高频的报错痛点，请对照自身设备进行排查。遇到对应情况时，请将加粗的关键词带入搜索引擎寻找特定教程。

**1. 无法进入 BIOS 或 U 盘引导菜单**
*   **现象**：插上 U 盘重启，电脑依然直接进入 Windows，没有给你选择 U 盘启动的机会。
*   **原因与对策**：各品牌进入 BIOS（底层固件设置）和 Boot Menu（启动菜单）的快捷键不同。详见 **2.5 BIOS 操作指南** 的快捷键表。开机时需高频连续敲击对应按键。
*   **搜索建议**：`[你的电脑品牌] 如何进入 BIOS 设置 U 盘启动`

**2. BitLocker 恢复密钥锁死（数据丢失高风险）**
*   **现象**：调整磁盘分区或修改 BIOS 设置后，重启进入 Windows 时，屏幕变成蓝色并要求输入一长串恢复密钥。
*   **原因与对策**：大部分预装 Windows 11 的电脑默认开启了硬盘加密（BitLocker）。主板环境的微小变动都会触发其防篡改机制。**在开始装机前，必须在 Windows 系统中提前备份 BitLocker 恢复密钥（保存到手机或 U 盘）。**（见 2.2 第 4 条）
*   **搜索建议**：`Windows 11 如何查找并备份 BitLocker 恢复密钥`

**3. Ubuntu 安装界面找不到电脑固态硬盘 (VMD/RST 问题)**
*   **现象**：成功进入 Ubuntu 安装界面，但在选择安装位置时，系统显示硬盘为空，找不到你切出来的 200G 空间，甚至连原来的 Windows 盘都看不到。
*   **原因与对策**：部分搭载 Intel 较新处理器的笔记本，默认开启了 Intel VMD (RST) 硬盘存储技术，Ubuntu 的内核默认缺少该技术的驱动。你需要在 BIOS 中将 SATA 模式从 `RAID/VMD` 更改为 **`AHCI`**。
*   *注意：直接在 BIOS 中修改会导致 Windows 蓝屏崩溃。必须配合 Windows 的"安全模式"进行无损切换。*
*   **搜索建议**：`双系统 VMD 改 AHCI 无损切换教程`

**4. 带有 Nvidia 独立显卡的电脑卡死/黑屏**
*   **现象**：在通过 U 盘引导，点击 "Install Ubuntu" 之后，屏幕长时间黑屏，或者卡在电脑品牌 Logo 界面死机，光标停止闪烁。
*   **原因与对策**：Ubuntu 内置的开源显卡驱动（Nouveau）与部分较新的 Nvidia 独立显卡存在严重冲突。你需要在 GRUB 引导界面（选择安装 Ubuntu 的那个黑底白字界面）按 `e` 键进入编辑模式，在 `quiet splash` 后面加上 **`nomodeset`** 参数，暂时禁用显卡驱动以完成安装。
*   **搜索建议**：`Ubuntu 安装过程黑屏死机 nomodeset 解决办法`

### 2.5 BIOS 操作指南：怎么进、改什么、怎么启动 U 盘

#### 2.5.1 进入 BIOS 与启动菜单的快捷键

| 品牌 | 进 BIOS 设置 | 进启动菜单 Boot Menu（一次性选启动盘） |
| --- | --- | --- |
| 联想 | `F2` | `F12` |
| 戴尔 | `F2` | `F12` |
| 华硕 | `F2` 或 `Del` | `F8` 或 `Esc` |
| 惠普 | `F10` | `F9` |
| 微星 | `Del` | `F11` |
| 小米 / Redmi | `F2` | `F12` |

- 开机看到品牌 logo 时**连续快速敲击** 对应按键（不是按住不放）；
- 不确定就看开机第一屏底部的提示（如 `Press F2 to enter setup`）；
- 没来得及按也没关系：Windows 下 `开始菜单 → 电源 → 按住 Shift 点"重启"`，进入 `高级启动 → 疑难解答 → 高级选项 → UEFI 固件设置`，也能直接进 BIOS。

#### 2.5.2 进 BIOS 后需要调整的设置（按顺序）

**① 关闭 Secure Boot（安全启动）**
- 位置：一般在 `Security` 或 `Boot` 菜单下，选项名 `Secure Boot` / `Secure Boot Control`；
- 改为 **Disabled**。不关闭的话 Ubuntu U 盘会被当作非法程序拦截，且后续 Nvidia 闭源驱动安装可能黑屏。
- 顺手把 **Fast Boot（快速启动）** 也关掉，避免它跳过 U 盘检测。

**② 确认启动模式为 UEFI**
- 位置：`Boot` 菜单下的 `Boot Mode` / `Boot Type` / `UEFI/Legacy 设置`；
- 保持 **UEFI**（部分机器写 `UEFI Only`，有 CSM 选项的保持关闭、不选 Legacy）。
- 现代 Windows 11 和 Ubuntu 24.04 都是 UEFI + GPT，这一步一般不用改，确认一下即可。

**③ 从 U 盘启动（关键）**

方法一（推荐）：按 Boot Menu 热键（如 `F12`），在列表里选择带 **`UEFI:` 前缀** 的 U 盘选项（如 `UEFI: SanDisk USB`）。它是一次性生效——装完重启会自动回到硬盘引导，不用再进 BIOS 改任何东西。

方法二：在 BIOS 的 `Boot Priority / Boot Order`（启动顺序）里把 U 盘调到第一位，按 `F10` 保存退出。**装完系统后记得再进 BIOS 把它放回硬盘启动**。

#### 2.5.3 常见问题

- **开机直接进 Windows，没进 U 盘**：确认 Boot Menu 里选的是 `UEFI: U盘` 而不是 `Legacy: U盘`；再检查 U 盘是否用 Rufus 按 **GPT + UEFI** 方式写入。
- **进不了 BIOS**：开机多按几次；或从 Windows 的"高级启动 → UEFI 固件设置"进入。
- **不确定自己改了什么**：每次改动前用手机拍张照，出问题能原样还原。

**搜索建议**：`[你的电脑品牌] 关闭 Secure Boot 设置 UEFI 引导 U 盘安装 Ubuntu`

### 2.6 安装后记：显卡驱动与常用配置

#### 显卡驱动

如果顺利进入 Ubuntu 24.04 桌面，说明你已完成基础部署。对于搭载 Nvidia 独立显卡的电脑，Ubuntu 默认使用开源的 Nouveau 驱动，其图形性能较弱。

- **图形界面方式**：打开 `Software & Updates（软件和更新）→ Additional Drivers（附加驱动）`，选择带有 `(proprietary, tested)` 标识的 Nvidia 闭源驱动并应用，重启即可。
- **命令行方式（遇到黑屏时）**：按 `Ctrl+Alt+F2` 无界面登录终端，执行：

```bash
sudo ubuntu-drivers autoinstall
sudo reboot
```

#### 装完建议做的小事

**1. 双系统时间不同步（Ubuntu 时间总慢 8 小时）**
Ubuntu 把 CMOS 时间当 UTC，Windows 当本地时间，导致两个系统时间相差 8 小时。终端执行：

```bash
timedatectl set-local-rtc 1
```

**2. 让 grub 默认记住上次选中的系统**
默认每次开机进 Ubuntu。编辑 `/etc/default/grub`，把 `GRUB_DEFAULT=0` 改为 `GRUB_DEFAULT=saved`，并在文件里加一行 `GRUB_SAVEDEFAULT=true`，然后更新：

```bash
sudo vim /etc/default/grub
# 修改 GRUB_DEFAULT=saved，并新增 GRUB_SAVEDEFAULT=true
sudo update-grub
```

这样开机选择界面会记住你上次选的是 Windows 还是 Ubuntu。

**3. 调整默认启动系统**
不想改 grub 的话，也可以直接进 BIOS 调整引导顺序，把 Windows 或 Ubuntu 放到第一位。
