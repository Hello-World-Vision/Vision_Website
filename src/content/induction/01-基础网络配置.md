作为 RM 视觉组的开发人员，你需要高频拉取 GitHub 源码、拉取 Docker 镜像、查阅 OpenCV/ROS 官方英文文档，以及调用 OpenCode 等 AI 辅助工具的外部 API。
无法稳定访问国际互联网，将被视为**不具备基础工程开发环境**。本文档为代理配置的基准要求。

*注意：本指南不再赘述上述文档已有的图文安装步骤，请具备基础的阅读理解能力并完成安装。*

### 1.2 系统架构与版本规定
安装时，不要随意下载。严格匹配你当前的开发系统环境：
- **Windows 用户**：下载 `x64-setup.exe`。
- **Ubuntu/Linux 用户 (视觉组标准开发机)**：优先下载 `amd64.deb` 进行 `dpkg` 安装，或使用 `AppImage` 格式。
- **内核切换**：安装完成后，进入 `Settings (设置) -> Clash Core`，**必须切换并使用 Meta 内核**，以确保对最新协议的支持与节点连通率。

### 1.3 终端网络环境隔离（TUN 模式）
你开启了客户端，你的 Chrome 浏览器能打开 Google，**不代表你的终端（Terminal）能拉取 GitHub 代码**。
默认的“系统代理（System Proxy）”仅接管系统层面的 HTTP/HTTPS 流量，大多数终端工具（如 `git`、`rosdep`、`opencode` CLI）默认会无视该设置。

**解决方案**：
1. **(推荐) 开启 TUN 模式**：在客户端设置中，安装并开启 Service 模式，随后开启 **TUN Mode（虚拟网卡模式）**。该模式将在底层接管网卡所有流量，此时终端无需任何额外配置即可直连外网。
2. **终端环境变量注入**：若无法使用 TUN 模式，在终端执行任何需要外网的指令前，必须手动注入代理端口（假设你的混合端口为 7897）：
   ```bash
   export http_proxy=http://127.0.0.1:7897
   export https_proxy=http://127.0.0.1:7897
   ```

## 2. 配置文件（Profile）的获取与注入
这部分在 `Clash Verge` 客户端仅负责本地流量的劫持与分发。要打通前往国际互联网的物理链路，必须获取上游服务器节点的配置文件（YAML 格式）。
当前获取出口节点的方式分为“商业订阅”与“自建节点”两条路径。针对视觉组的研发节奏，现下发选型基准与执行纪律。

### 2.1 方法1：商业订阅（Managed Subscription）—— 【首选】
**工程定义**：
向第三方网络服务商（俗称“机场”）按周期租赁带宽与节点使用权。服务商负责维护海外服务器集群、负载均衡以及应对 GFW（防火墙）封锁。你将获得一个包含数十个全球节点的 URL 链接。

**工程优劣势评估**：
- **优势 (High SLA)**：高可用性。网络延迟极低且吞吐量大，能瞬间满足拉取庞大 Docker 镜像或 ROS 依赖包的需求。多地区节点可随意切换，完美解决部分 AI API（如 OpenAI、Claude）的区域 IP 封锁问题。
- **劣势 (Security Risk)**：底层物理服务器不受你控制，数据流量经过第三方中转，存在潜在的中间人监控风险。

**【视觉组开发的建议】**：
对于视觉组成员，**建议采用商业订阅模式**。
在 RoboMaster 备赛期，你们最核心的资产是**时间**。你们的任务是写出极致优化的 C++ 视觉算法，而不是去当兼职的网络运维。非常不建议将宝贵的研发时间浪费在研究翻墙协议和修复被墙的 IP 上。

### 2.2 方法2：自建节点（Self-hosted Infrastructure）
**工程定义**：
自行在海外云厂商（如 AWS、Azure、DigitalOcean、BandwagonHost）租赁虚拟专用服务器（VPS），通过 SSH 登录 Linux 系统，手动配置 Xray、Sing-box 等底层网络协议，搭建专属的代理服务端。

**工程优劣势评估**：
- **优势 (Data Privacy)**：绝对的物理与数据控制权，独享独立 IP（干净，极少被目标网站拉黑）。
- **劣势 (Low SLA & High Cost)**：单点故障风险极高。一旦该 VPS 的 IP 被 GFW 识别并封锁，你必须自费更换 IP 并重新部署。搭建过程涉及复杂的 Linux 运维、证书签发与端口放行，极度消耗精力。

**【视觉组开发的建议】**：
**不建议新人在备赛期间尝试自建节点。** 除非你已经完全掌握了当前所负责项目的视觉算法架构且任务进度超前，否则禁止这种低效的“重复造轮子”行为。我们不需要个人运维，我们需要按时交付的经过测试的，优秀的，领先的视觉代码。

#### 2.3.2 注入操作步骤
当你注册并在网站控制台找到了你的订阅 URL（通常以 `http` 或 `https` 开头，一般点击网站上的“一键订阅”或“复制 Clash 订阅链接”即可获取）后，执行以下操作：

1. **执行注入**：打开 Clash Verge，进入 `Profiles（配置）` 选项卡，在顶部输入框粘贴你的订阅 URL，点击 `Import（导入）`。
2. **校验握手**：导入完成后，右键点击该配置文件，选择 `Update（更新）`。随后进入 `Proxies（代理）` 选项卡，点击右上角的测速图标。凡是显示具体数字（如 `150ms`）的节点，即代表物理链路贯通。
3. **策略组选择**：在代理组策略中，默认选择 `Rule（规则模式）`。日常不需要开启 `Global（全局模式）`，这会导致你访问国内镜像源（如清华 pip 源、阿里 apt 源）时流量绕道海外，致使拉取速度暴跌。

**【数据安全】**：
由于我们采用第三方商业订阅，出于安全考虑，建议所有核心业务代码的同步必须依托于经过 SSH 密钥认证或 HTTPS 加密的 Git 仓库。
